📖 RESOLUÇÃO DE PROBLEMAS:
--------------------------

❌ "Unauthorized"
   → Token do bot está errado
   → Recrie o bot no @BotFather

❌ "Chat not found"
   → Chat ID está errado
   → Bot não foi adicionado ao grupo
   → Use @userinfobot para pegar o ID

❌ "Bot was blocked by the user"
   → Desbloqueie o bot no Telegram
   → Inicie conversa com /start

❌ Mensagem não formatada
   → Problema com escape de caracteres
   → Verifique telegram_bot.py
